# Food Delivery System

A complete, professional, and fully functional **Online Food Ordering and Delivery System** built with PHP 8+ and MySQL. This project is structured as a premium academic submission suitable for obtaining Distinction-level grades.

---

## 🚀 Quick Start / Installation

1. **Clone/Copy Project**: Ensure the project folder is placed under your local server root (e.g. `c:\xampp\htdocs\FoodDelivery` or `c:\laragon\www\Food_delivery_WDD`).
2. **Start Local Server**: Open XAMPP/Laragon and ensure Apache and MySQL services are running.
3. **Database Initialization**:
   - Open your browser and navigate to: `http://localhost/Food_delivery_WDD/install.php` (or adjusted local port path).
   - This script will automatically create the database `food_delivery`, construct the tables with constraints, and seed categories, restaurants, menu items, and test users.
4. **Done**: You can now navigate to `http://localhost/Food_delivery_WDD/index.php` and explore the site!

## 🛡️ Security Implementations

1. **SQL Injection**: Prevented by compiling all database queries through `PDO` prepared statements and parameterized inputs.
2. **Cross-Site Scripting (XSS)**: Handled by escaping outputs using `htmlspecialchars($data, ENT_QUOTES, 'UTF-8')` wrapped in an `e()` shortcut.
3. **Cross-Site Request Forgery (CSRF)**: Thwarted by checking state-matching random tokens in POST bodies against active session variables.
4. **Credential Safeguard**: High-security password hashing uses the strong `Argon2` or `Bcrypt` algorithm through `password_hash()`.
5. **Secure Authentication Guards**: Role middleware prevents unauthorized users from loading admin templates or customer invoice files.
